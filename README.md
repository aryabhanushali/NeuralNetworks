# NeuralNetworks
PyTorch and MicroTorch
This project explores the implementation of neural networks using both PyTorch and a custom deep learning framework I developed called MicroTorch. In the pytorch.ipynb notebook, I built a standard neural network using PyTorch's intuitive high-level API, allowing me to efficiently handle model training, backpropagation, and evaluation. In contrast, microTorch.ipynb showcases a neural network built entirely from scratch, where I implemented core components like tensors, autograd, linear layers, activations, and loss functions manually. This hands-on process helped me gain a deeper understanding of how neural networks work under the hood, including the mechanics of forward and backward passes. Through this project, I learned the value of abstraction in modern libraries like PyTorch while also appreciating the complexity and elegance of the foundational math and engineering that makes deep learning possible.
